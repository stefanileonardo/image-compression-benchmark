# Duplicate K = 16 run

Per-tile SMoE parameters from the original folder `16k_100i_3535s`. It holds $K=16$
models for three of the five images, and its stitched reconstructions were byte-identical
to those of the complete $K=16$ run, so it is not an independent result.

It is kept as evidence only: no script loads it and it enters no table. The full account
is in [`docs/PROVENANCE.md`](../../docs/PROVENANCE.md) (section *The disputed duplicate*)
and in [`docs/AUDIT.md`](../../docs/AUDIT.md) (finding B3).
