read by the pipeline, the tests or the paper. It is kept so that the corrections recorded
in [`docs/AUDIT.md`](../docs/AUDIT.md) can be checked against what they replaced.

| Folder | Contents |
|---|---|
| [`notebooks/`](notebooks/README.md) | The original notebooks, superseded by `src/` and `scripts/` |
| [`superseded_figures/`](superseded_figures/README.md) | Figures exported before the correction; not to be used |
| [`smoe_duplicate_K016_run/`](smoe_duplicate_K016_run/README.md) | A second $K=16$ parameter set that is not an independent run |
